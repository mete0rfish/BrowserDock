# BrowserDock 한국어 학습 가이드

> 브라우저의 수명과 자동화 연결의 수명을 나누어 생각하는 것이 이 프로젝트를 이해하는 출발점입니다.

BrowserDock은 Chrome을 별도 프로세스로 관리하고, 독립적인 CDP 연결과 교체 가능한 WebDriver 연결을 제공하는 .NET 라이브러리입니다. 이 Wiki는 API 목록을 외우기보다 **사용 예제에서 실제 코드와 테스트까지 따라가는 방법**을 설명합니다.

C# 기본 문법을 읽을 수 있다는 전제로 작성했습니다. CDP, WebDriver 세션, 프로세스 관리에 익숙하지 않아도 02장부터 차례로 읽을 수 있습니다.

## 학습 순서

**먼저 실행하기:** 01장 → 03장 → 09장. 실행 가능한 환경과 API 사용 규칙부터 확인합니다.

**구조 이해하기:** 02장 → 04장 → 05~08장. 공개 API에서 내부 구현으로 들어갑니다.

**직접 변경하기:** 10장 → 11장 → 12장. 자원 소유권과 테스트를 확인한 뒤 작은 변경을 시도합니다.

## 공통 예제의 흐름

브라우저를 시작하고 테스트 페이지를 엽니다. WebDriver로 제목이나 요소를 확인한 다음 연결을 해제합니다. CDP로 페이지를 제어하고, 새 WebDriver 연결을 얻어 작업을 이어갑니다. 마지막에는 소유한 자원을 정리합니다.

**연결만 해제하는 실험과 페이지를 새로 여는 실험은 다릅니다.** 연결 해제 자체는 문서를 다시 로드하지 않지만, navigation은 DOM과 페이지 상태를 바꿀 수 있습니다. 08장의 참조 실험에서는 이를 구분하기 위해 재연결 사이에 이동하지 않습니다.
