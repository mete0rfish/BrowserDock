# 부록 C. 제한사항과 검증 상태

> 문서 기준: `8a8612fffe681334c4e6ec8384ab18a6ba66271f` / 검토일: 2026-09-23

이 페이지는 기준 코드의 범위와 저장소에 기록된 근거를 구분합니다. 모든 최신 workflow를 감사한 실시간 상태판은 아닙니다. 새 릴리스를 판단할 때는 해당 커밋의 실행 결과를 별도로 확인하세요.

## 현재 구현의 범위

| 항목 | 기준 코드·문서의 범위 |
|---|---|
| 실제 브라우저 호스팅 | Windows 11 x64, headed Chrome |
| 제품 대상 프레임워크 | net481, net8.0, net10.0 |
| 전체 소스 빌드 | .NET 10 SDK 필요 |
| Chrome/ChromeDriver 준비 | 호출자 제공, 자동 다운로드 없음 |
| 호환성 검사 | M115 이상, MAJOR.MINOR.BUILD 일치 |
| 개인 기본 프로필 | 사용하지 않음 |
| 외부 Chrome attach와 소유권 인수 | 현재 범위 밖 |
| headless, GUI 입력 | 현재 범위 밖 |
| 실제 driver patch recipe | 검증된 내장 recipe 없음 |
| 사이트 탐지·WAF·CAPTCHA 통과 | 보장하지 않음 |

범위 밖이라는 말은 구현 난이도와 무관하게 현재 계약으로 약속하지 않는다는 뜻입니다. 새로운 요구는 소유권, 상태 전이, 테스트 범위를 함께 설계해야 합니다.

## 세 가지 근거를 구분합니다

**코드에서 확인:** lifecycle 직렬화, epoch 검사, 독립 CDP, guarded API와 패치 확장 구조가 존재합니다. 이는 구현을 읽고 확인한 사실입니다.

**저장소에 남은 과거 실행 기록:** 2026-09-12 기록에는 macOS arm64에서 전체 Release 빌드와 net10 공통 시험 core 44개·Legacy 22개 통과 등이 있습니다. 같은 기록은 Windows 실제 Chrome 시험을 그 환경에서 실행하지 않았다고 명시합니다.

**이번 Wiki 작성의 범위:** 기준 소스와 문서를 대조해 학습 내용을 작성했습니다. Windows 실제 브라우저 수용 시험을 새로 수행하거나 모든 예제를 해당 환경에서 검증한 작업은 아닙니다. 본문의 기대 동작을 실제 실행 로그로 오해하지 마세요.

이후 CI 정의와 의존성 변경이 있으므로 과거 통과 건수를 현재 커밋의 보증으로 재사용하지 않습니다. 최신 실행 결과를 추가할 때는 소스 커밋과 runtime, Chrome/ChromeDriver 버전, 결과 파일을 함께 적습니다.

## 아직 구분해서 검증할 항목

실제 Windows의 세션 교체와 브라우저 유지, 반복·병렬 실행 중 자원 정리, net481 소비 앱 실제 실행, 실제 바이너리 recipe, 배포 환경과 패키지 소비 경로는 각자 근거가 필요합니다.

이 목록은 오늘의 모든 항목이 반드시 미완료라고 단정하는 목록이 아니라, 릴리스 판단에서 **각 항목의 실행 증거를 따로 요구해야 한다는 체크 포인트**입니다. 자세한 추적은 기존 테스트 계획과 구현 기록을 사용합니다.

## 공개 배포 상태를 읽는 법

기준 README는 실험 단계이며 공개 후보 버전을 `0.2.0-alpha.1`로 설명합니다. 공개 NuGet 게시와 프로젝트 라이선스·권리자 확정이 대기 상태라고 기록되어 있습니다.

이 문서만 보고 공개 패키지가 존재하거나 라이선스가 확정되었다고 가정하지 않습니다. 게시 시점의 실제 패키지와 라이선스 파일을 확인해야 합니다. 릴리스 절차는 [기여와 릴리스](ko-Contributing.md)에서 연결합니다.

## 개선 항목 제안 방법

기능 이름만 적기보다 필요한 사용 시나리오, 현재 제한, 바뀌는 소유권이나 공개 계약, 검증 가능한 수용 기준을 함께 적습니다. 기능 제안과 이미 승인된 로드맵을 같은 상태로 표시하지 않습니다.
